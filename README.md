# Análise de anúncios de veículos

Este projeto apresenta um aplicativo web desenvolvido com Streamlit
para explorar dados de anúncios de venda de veículos.

## Funcionalidades

O aplicativo permite:

- visualizar um histograma da quilometragem dos veículos;
- visualizar um gráfico de dispersão relacionando quilometragem e preço;
- explorar os gráficos de forma interativa utilizando Plotly.

## Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- Plotly Express
